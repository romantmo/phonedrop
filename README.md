# PhoneDrop

Чат между телефоном и твоими компьютерами по QR-коду: текст, фото, видео, файлы и голосовые — в обе стороны.
На компьютере ничего не устанавливается, а на телефоне это приложение ставится прямо с сайта (PWA).

## Как пользоваться

1. На компьютере открой сайт — появится QR-код.
2. Выбери режим этого компьютера:
   - 🏢 **Чужой** (по умолчанию) — переписка удалится через минуту после закрытия вкладки;
   - 🏠 **Мой** — компьютер запомнится, переписка сохранится (файлы — 30 дней).
3. Отсканируй QR телефоном (камерой или кнопкой QR в приложении). Код одноразовый.
4. Переписывайся. У каждого компьютера на телефоне свой чат.
   - **На компьютере:** перетащи файл в окно или нажми Ctrl+V, чтобы отправить скриншот на телефон.
   - **На Android:** в галерее «Поделиться» → PhoneDrop (уйдёт на компьютер, который сейчас в сети).
5. Включи 🔔 уведомления — сообщение придёт, даже когда приложение закрыто.

О защите и хранении данных — в [SECURITY.md](SECURITY.md).

## Структура проекта

```
app/main.py                      сервер (FastAPI): аккаунты, компьютеры, чаты, файлы, уведомления, защита
app/static/desktop.html|js|css   страница компьютера: QR-код, режим, чат
app/static/phone.html|js|css     приложение для телефона: список компьютеров и чаты
app/static/chat.js|css           общий чат: сообщения, отправка, голосовые, push
app/static/sw.js                 service worker: установка приложения и push-уведомления
app/static/manifest.webmanifest  описание PWA (иконка, меню «Поделиться»)
tests/test_app.py                автотесты (их запускает CI)
```

Данные хранятся в `DATA_DIR`: база `phonedrop.db` (SQLite), папка `files/` и ключ уведомлений `vapid_private.pem`.
**В Docker эта папка должна быть томом (volume)** — иначе при каждом деплое переписка пропадёт.

## Запуск на своём компьютере

Нужен Python 3.11+.

```bash
python -m venv .venv
.venv\Scripts\activate             # Linux/Mac: source .venv/bin/activate
pip install -r requirements-dev.txt

pytest -q                          # тесты
uvicorn app.main:app --port 8000
```

Открой `http://localhost:8000`. Телефону нужен HTTPS — он появится после деплоя на сервер.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PUBLIC_URL` | адрес из запроса | Адрес сайта для QR-кода, например `https://drop.rbgen.com` |
| `DATA_DIR` | `/tmp/phonedrop` | Где хранятся база, файлы и ключ уведомлений |
| `MAX_UPLOAD_MB` | `500` | Лимит на одну отправку |
| `CHAT_QUOTA_MB` | `4096` | Сколько места может занять один чат |
| `MIN_FREE_DISK_MB` | `2048` | Не принимать файлы, если на диске меньше места |
| `FILE_TTL_DAYS` | `30` | Сколько дней хранятся файлы |
| `REMEMBER_DAYS` | `90` | Через сколько дней без заходов отключать «мой» компьютер |
| `PC_GRACE_SEC` | `60` | Через сколько секунд после закрытия вкладки удалять «чужой» компьютер |
| `PAIR_TTL_SEC` | `300` | Сколько живёт QR-код |
| `VAPID_SUBJECT` | `PUBLIC_URL` | Контакт для push-сервисов (`mailto:…` или адрес сайта) |
| `APP_VERSION` | `dev` | Версия, которую показывает `/healthz` (заполняет CI/CD) |

## План версий

- **v1 (сейчас):** чаты телефон ↔ мои компьютеры, файлы и голосовые, режимы «чужой/мой», уведомления, защита.
- **v2:** друзья — переписка с другими людьми (приглашение по ссылке, контакты).
- **v3:** звонки (WebRTC).
